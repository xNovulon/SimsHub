# Glossary

The app's words, one way each, in every language. Use these in new messages so the same thing is always called the
same. Messages live in `<code>.json` next to this file; `en.json` is the source.

## Rules

- Plain, neutral, descriptive. No first person ("I", "we"), no mascot, no jokes, no exclamation marks.
- Buttons: 1-3 words, a verb first where it fits ("Send to game", "Pick a file").
- Address the user as `tú` (es), `você` (pt-BR), `vous` (fr), `du` (de), `tu` (it), `ty` (pl), the way The Sims 4
  and most modding tools do in those languages.
- Leave untranslated: WickedWhims, The Sims 4, TURBODRIVER, Tray, Mods, Mods_parked, file names (`My poses.json`,
  `config.json`), bone names (`b__Pelvis__`), WickedWhims tag names (`CUM_INSIDE`), key names (Ctrl, Shift, Alt, Esc),
  units (s, cm, BPM, MB), brand and feature names: Novulon's Wicked Animator, Say it, Pose Player, MediaPipe.
- Placeholders (`{name}`) and plural blocks (`{n, plural, one {...} other {...}}`) stay exactly as in English; only the
  words around them change. Polish needs `one`, `few` and `many` forms (and `other` for fractions); the other
  languages `one` and `other`.
- A message that starts or ends with a space (a sentence added to another) keeps that space.
- Say it reads sentences in English only: its example sentences stay English, everything around them is translated.
